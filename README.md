## Privacy and source-data classification

Never commit credentials, API tokens, nonpublic client information, unpublished
proprietary source extracts, private reviewer attestations, sensitive manifests,
or other secrets. A database holding *public* Coinbase BTC/USD price bars is
stored on the `data/btc-usd-daily` Git branch. Historical Bitstamp/Bitfinex
Stage-6 experiments use separate data fetched into temporary GitHub Actions
workspace directories; selected results are kept as expiring Artifacts.

Only authorized repository administrators can change GitHub visibility.
Changing a README, workflow label, or branch name does **not** change access.
Before storing proprietary IP, confirm repository and artifact permissions,
inspect historical commits and forks, and rotate any previously exposed secret.
Making a public repo private cannot revoke copies obtained while it was public.
